# Kitten Space Agency 简体中文汉化

适用游戏版本：**2026.10.13.5602** · 平台：**Windows**

本仓库提供简体中文汉化补丁、译文源码和安装工具。**不包含游戏本体、原始游戏 DLL、完整修改版游戏 DLL、游戏素材、存档或 Windows 字体。必须自行准备对应版本的游戏。** 游戏程序修改以差分补丁提供，安装器用你的原版文件在本机生成汉化文件。

## 下载与安装

1. 先保存进度并正常退出游戏，确认你使用的是 **2026.10.13.5602**。
2. 在本页点击 **Code → Download ZIP**，下载后**完整解压**到一个可写入的文件夹。不要在压缩包里直接运行，也不要只下载某一个文件。
3. 双击解压目录中的 **`简体中文启动.cmd`**。
4. 首次运行会提示输入游戏安装目录。粘贴**包含 `KSA.exe` 的文件夹路径**，然后按回车，例如 `D:\Games\Kitten Space Agency`。不是 `KSA.exe` 文件本身，也不是其 `Content` 子文件夹。
5. 安装器会校验游戏版本和补丁、自动备份原始文件、生成并安装汉化，然后启动中文游戏。以后使用同一个 **`简体中文启动.cmd`** 即可，安装位置会自动记住。

补丁可以放在游戏目录外；无需把整个仓库复制到游戏安装目录。若游戏目录没有写入权限，请通过 Windows 为自己的安装目录配置写入权限，或使用有写入权限的游戏副本。

本汉化使用 Windows 黑体。安装时会从本机 `%WINDIR%\Fonts\simhei.ttf` 复制一个独立字体副本，不会修改系统字体。如果提示缺少黑体，请先在 Windows 中文语言/字体设置中安装对应字体，再重试。

## 切换语言与还原

执行以下操作前，请先正常退出游戏。

| 入口 | 用途 |
| --- | --- |
| `简体中文启动.cmd` | 安装或校验汉化，并以中文启动 |
| `仅安装汉化.cmd` | 只安装汉化，不启动游戏 |
| `原版英文启动.cmd` | 使用同一套程序以英文启动，保留汉化供下次切换 |
| `还原原始游戏.cmd` | 恢复备份的原版程序及语言注册文件，移除本补丁新增的文件 |

安装后直接运行游戏目录里的 `KSA.exe` 默认使用简体中文。英文启动入口只为新启动的进程设置语言，不改变存档或控制绑定。

原始备份保存在**游戏安装目录的 `.ksa-zh-backup` 文件夹**，请保留该文件夹，直到不再需要还原。本安装器只处理补丁涉及的文件，不读写用户存档。还原后备份仍会保留。

如果移动了游戏目录，可删除补丁解压目录中的 `.install-path.txt`，下次运行时重新输入路径。

也可以在 PowerShell 中明确指定目录：

```powershell
# 进入本补丁解压目录后运行，只安装，不启动游戏。
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Action Install -GameDirectory 'D:\Games\Kitten Space Agency'

# 还原原始文件。
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Action Restore -GameDirectory 'D:\Games\Kitten Space Agency'
```

## 已有补丁与游戏更新

首次安装应使用上述版本的**干净原版游戏文件**。如果之前安装过其他版本的汉化，请先用旧补丁自己的还原入口和备份恢复原版，再安装本包。不要直接覆盖其他补丁，也不要删除旧备份后强行安装。

本安装器支持同一包重复安装，会校验已有原始备份。遇到陌生文件、版本不符或补丁校验失败时，会停止，保留现有文件。游戏升级后，请等待对应版本的补丁；本包不会自动套用到其他游戏版本。

## 汉化范围

- **3,670 条词典记录**，含 **213 条原生本地化文本**。
- 适配 2026.10.13.5602，新增 104 条词典记录，涵盖自动点火燃料耗尽警报、高光抗锯齿、尾焰轨迹阴影、爆炸效果设置和调试面板。新增部件“支撑杆 D”已翻译。
- 当前启用资源中的 **180 个完整部件模板**均有中文名，其中 **177 个为建造界面可选部件**。
- 覆盖储箱、分离器、对接端口、整流罩、鼻锥、助推器、姿态控制推进器、电池、太阳能电池板、服务舱和着陆支架等名称。
- **64 条资源描述、101 条资源提示**，以及设置、控制绑定、保存/加载、飞行与轨道规划等界面文字。
- 修复动态提示中的型号与加号漏译、小号提示字体和中文富文本换行。

部件的 W/H 规格编码、型号、技术缩写及变体字母保留，Half/Quarter 尺寸名称改为 0.5/0.25。固定仪表刻字、部分内部子部件名称、历史更新日志及底层诊断信息仍可能保留英文。未修改飞行物理、部件资源定义或存档结构。

## 验证与维护

中文和英文模式各 **1,270 项运行库检查通过**，含部件名称、带隐藏 ID 的按钮和完整 ImGui 提示。资源覆盖报告见 [`reports/`](reports)。本轮仅观察新版启动配置窗口的中文显示；未检查新版游戏内菜单、设置及部件逐项悬停画面。

发布包另外验证了：差分重建后的文件哈希与本地已验证汉化一致、Windows PowerShell 5.1 安装、重复安装、未知同名文件保护、错误游戏版本拒绝、损坏补丁拒绝、完整还原以及存档文件保持不变。结果见 [`reports/distribution-tests.json`](reports/distribution-tests.json)。

- `src/translations*.tsv`：译文源码，采用 `原文|译文` 格式。
- `src/ChineseLocalization.cs`：汉化运行库源码。
- `payload/`：中文语言资源与汉化运行库 `KsaChinese.dll`。
- `patches/`：只能结合对应原始文件使用的差分补丁。
- `scripts/install.ps1`：无需 Python 或额外开发工具的安装/还原脚本。
- `tools/build-distribution.py`：维护者从本地已验证的汉化工作区重新生成发布文件的工具，需要 Python；普通玩家不需要运行。
